## 🛠️ **Tecnologie Utilizzate**

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Styling**: Tailwind CSS con design system personalizzato
- **Charts**: Chart.js con plugin datalabels
- **Backend**: Firebase Firestore
- **Storage**: LocalStorage + Cloud sync
- **Icons**: SVG icons inline

## 🔧 **Installazione e Utilizzo**

1. Apri il file `GestioneClienti_Firestore.html` in un browser moderno
2. L'applicazione si caricherà automaticamente
3. Inizia aggiungendo sessioni di lavoro cliccando sui giorni del calendario
4. Utilizza la sezione Analytics per visualizzare i report
